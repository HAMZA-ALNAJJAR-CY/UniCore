# Database status

## Implemented

None. Phase 0 uses no database, IndexedDB, localStorage, Supabase, remote API, data schema, migrations, or sample academic records. Notifications live only in React memory and disappear on reload.

## Planned

Courses, lectures, notes, attachments, materials, timetable, and calendar events will need domain and persistence design in later phases. Offline ownership, record identifiers, migrations, conflict resolution, sync metadata, file lifecycle, and deletion behavior must be specified before implementation. This document does not approve or define a database schema.
